Cómo usar la ruleta

  1. El cliente escanea el QR del cartel y baja hasta la ruleta.
  2. Tomás su celular y escribís este código en Código de Brian. El cliente no lo ve: aparece con puntos.
  3. El cliente gira delante tuyo.
  4. Si gana, en la pantalla queda el premio, el código y la hora del giro. El premio vale para el servicio de hoy.
  5. El código cambia solo a la medianoche. No lo compartas.
